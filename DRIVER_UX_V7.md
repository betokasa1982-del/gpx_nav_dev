# Driver UX V7 — True Navigation Cockpit

V7 makes Driver Mode a separate full-screen cockpit rather than restyling the planning UI.

- Planning/developer chrome is hidden only while navigation is active.
- Full-screen map remains the visual base.
- Large manoeuvre card is isolated at left.
- Speedometer is an independent automotive instrument at upper-right.
- Next Stop is a dedicated lower-right dock.
- Route progress is a compact lower-center pill.
- Live-cycle/developer panels and Leaflet controls are removed from Driver Mode.
- Intrusive custom PWA install banner no longer auto-opens.
- Navigation/GPS/playback/stop logic is unchanged.
